# AttendanceToken Entity Documentation

## Overview
The `AttendanceToken` class represents a QR code token generated by teachers for students to scan and mark attendance. Tokens have expiration times for security.

## File Location
`src/main/java/com/attendance/entity/AttendanceToken.java`

## Libraries Used
No external validation libraries. Uses standard Java time APIs for expiration checking.

## Class Structure

### Fields

#### `id` (String)
- **Purpose**: Unique identifier for the token
- **Why**: Required for Firebase database operations

#### `token` (String)
- **Purpose**: Unique token string (UUID) embedded in QR code
- **Why**: Students scan QR code containing this token to mark attendance

#### `subjectId` (String)
- **Purpose**: ID of the subject for which this token is valid
- **Why**: Links token to specific subject (stored as ID for Firebase compatibility)

#### `teacherId` (String)
- **Purpose**: ID of the teacher who generated this token
- **Why**: Links token to teacher (stored as ID for Firebase compatibility)

#### `expiresAt` (String)
- **Purpose**: Timestamp when token expires
- **Format**: ISO LocalDateTime string
- **Why**: Security measure - tokens expire after a set time (default 2 minutes)

#### `createdAt` (String)
- **Purpose**: Timestamp of token creation
- **Format**: ISO LocalDateTime string
- **Why**: Audit trail

#### `isActive` (Boolean)
- **Purpose**: Whether the token is currently active
- **Default**: `true`
- **Why**: Allows manual deactivation of tokens

## Constructors

### `AttendanceToken()`
- **Purpose**: Default constructor
- **Why**: Required for Firebase deserialization
- **Functionality**: Initializes `createdAt` with current timestamp

### `AttendanceToken(String token, String subjectId, String teacherId, String expiresAt)`
- **Purpose**: Parameterized constructor
- **Why**: Convenient way to create token entities
- **Functionality**: Sets all token properties and sets `isActive` to `true`

## Methods

### Getters and Setters
- **Purpose**: Standard accessor methods
- **Why**: Required for JavaBean compliance and Firebase serialization

### `isExpired()`
- **Purpose**: Checks if token has expired
- **Returns**: `boolean`
- **Logic**: Compares `expiresAt` with current time
- **Why**: Used by service layer to validate tokens before allowing attendance marking
- **Error Handling**: Returns `false` if parsing fails (fails safe)

## Usage Example
```java
AttendanceToken token = new AttendanceToken();
token.setToken(UUID.randomUUID().toString());
token.setSubjectId(subjectId);
token.setTeacherId(teacherId);
token.setExpiresAt(LocalDateTime.now().plusMinutes(2).toString());
token.setIsActive(true);
```
